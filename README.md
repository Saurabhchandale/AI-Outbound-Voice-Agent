# AI Voice Agent – Divyasree "Whispers of the Wind (WOW)"

## Project Overview

This project demonstrates an **AI-powered outbound voice agent** built for **Divyasree Developers** to automate lead qualification for their premium plotted development, **Whispers of the Wind (WOW)**.

The AI Voice Agent acts as a professional property consultant that introduces the project, qualifies prospective buyers, answers common questions, and schedules follow-up calls with Property Experts. The conversation is designed to be natural, premium, and non-intrusive, with an average duration of **2–3 minutes**.

---

## Business Objective

The objective of this AI Voice Agent is to:

* Introduce the Whispers of the Wind project professionally.
* Build rapport with prospective customers.
* Qualify leads using business-defined criteria.
* Answer frequently asked questions.
* Schedule callbacks with Property Experts.
* Reduce manual lead qualification efforts.
* Improve customer engagement and sales productivity.

## Lead Qualification Parameters

The AI agent qualifies customers using four checkpoints:

* **Intent** (Self-use, Investment, Weekend Home, Exploring)
* **Location Preference** (Nandi Hills / Devanahalli Corridor)
* **Budget Fit** (Starting from ₹92.4 Lakh)
* **Purchase Timeline** (Immediate, 3 Months, 6 Months, 1 Year)
